# Security Policy

## Reporting a Vulnerability

Please report security issues privately by opening a [Security Advisory](https://github.com/DataJuggler/DataJuggler.Excelerate.Office/security/advisories/new) on this repository rather than a public issue.

If the problem is in the underlying NPOI code, it likely affects the upstream project too. Please also report it to [NPOI](https://github.com/nissl-lab/npoi/security/advisories/new) so it can be fixed for everyone.
