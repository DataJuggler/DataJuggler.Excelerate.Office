# DataJuggler.Excelerate.Office

An independent build of [NPOI](https://github.com/nissl-lab/npoi) 2.8.1, the .NET port of Apache POI, for reading and writing Excel files (.xlsx and .xls). Word and PowerPoint support has been removed.

It is built from the Apache 2.0 NPOI source **without the OSMF EULA** that ships with the official NPOI packages, so anyone can use it, commercial or not, under the plain Apache 2.0 license.

Nearly all of this code is the work of Tony Qu and the NPOI contributors. This package is not affiliated with or endorsed by the NPOI project or Nissl LLC.

Namespaces are renamed from `NPOI.*` to `DataJuggler.Excelerate.Office.*` (class names are unchanged), so this package can be used alongside the official NPOI package without conflicts.

Source and details: https://github.com/DataJuggler/DataJuggler.Excelerate.Office
